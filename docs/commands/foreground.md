# `nordrelay foreground`

Run the connector in the current terminal.

## Usage

```bash
nordrelay foreground
```

## Options

| Option | Description |
| --- | --- |
| `--home <path>` | Use a custom NordRelay home directory |

## Example

```bash
nordrelay foreground
```

## Notes

Foreground mode is useful for development, direct log inspection, and process managers that already handle lifecycle.
