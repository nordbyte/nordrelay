# `nordrelay version`

Print the installed NordRelay version.

## Usage

```bash
nordrelay version
```

## Options

| Option | Description |
| --- | --- |
| `--version`, `-v` | Top-level shortcut for version output |

## Examples

```bash
nordrelay version
nordrelay --version
```

## Notes

The WebUI **Version** page provides richer status, including agent CLI versions, installed paths, latest-version checks, update jobs, and update logs.
