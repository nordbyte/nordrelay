# `nordrelay stop`

Stop the connector and WebUI processes managed by NordRelay.

## Usage

```bash
nordrelay stop
```

## Options

| Option | Description |
| --- | --- |
| `--home <path>` | Use a custom NordRelay home directory |

## Example

```bash
nordrelay stop
```

## Notes

Stopping NordRelay does not necessarily terminate external agent CLIs you started outside NordRelay.
