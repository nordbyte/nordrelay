# `nordrelay status`

Show connector and WebUI process status.

## Usage

```bash
nordrelay status
```

## Options

| Option | Description |
| --- | --- |
| `--home <path>` | Use a custom NordRelay home directory |

## Example

```bash
nordrelay status
```

## Notes

Use this before `restart` or `stop` when you need to know which NordRelay-managed processes are currently running.
